# SCP Foundation Catalogue Application

## COMP.6210 Assignment 1

A React Single Page Application developed for the SCP Foundation catalogue.

## Description

This project provides an interactive catalogue system for browsing SCP Foundation objects.

Users can:
- Search SCP entries
- Filter SCP objects by classification
- View detailed SCP information
- Browse SCP images and descriptions

## Features

- SCP catalogue homepage
- Search functionality
- Object Class filtering:
  - Safe
  - Euclid
- SCP detail page
- JSON-based data management
- Responsive user interface

## Technologies Used

- React JS
- Vite
- JavaScript
- CSS
- JSON
